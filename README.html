CDDM Live
Version 1.1 • GNSS Geodesy Tool

Effortless Archive Monitoring.

Autonomous desktop verification engine engineered to track real-time telemetry, audit historical gaps, and verify observation completeness across NASA CDDIS GNSS archives.

Engineered for Reliability

⚡ Real-Time Live Telemetry

Streams current-day arrivals from Hour 00 to active UTC, instantly logging file availability and arrival timestamps.

📊 Offline Gap Audit Matrix

Parses station logs completely offline without querying NASA CDDIS, eliminating latency and avoiding account rate limits.

↻ Intelligent Gap Re-Check

Skips all verified 24/24 complete days, focusing background network requests strictly on missing or incomplete dates.

🛡️ Strict 24/24 Verification

Requires every hour of a past Julian Day to be confirmed before showing a green badge, eliminating false positives.

📦 Automated Daily 24h Fallback

Verifies daily composite archives (*.crx.gz) if real-time hourly telemetry experienced a network dropout.

📈 In-Place Progress Feedback

Tracks active multi-slot scans with a dynamic in-place percentage indicator and smooth indeterminate visual cues.

Status Badges at a Glance

✔ DOY Complete (24/24 Slots): All 24 hourly observation segments are verified and logged in local storage.
✖ DOY Incomplete / Missing: File dropouts detected or fewer than 24 hours logged on a past Julian Day.
○ DOY Unaudited Day: Historical past day that has not yet been scanned locally or queried on CDDIS.
PENDING Slot In Flight: Active hour currently queued for network verification or awaiting ingest grace period.

Automated Setup & Launch

Option A: Linux (Ubuntu / Debian / Fedora)

  1. Extract Archive & Open Terminal in Directory: 
    unzip CDDM_v1.1_Linux.zip
cd CDDM
  2. Run Setup Script: 
    ./install.sh

    Builds the local virtual environment, installs PySide6, and establishes Mozilla root CA trust store (certifi).

  3. Launch Application: 
    ./run_cddm.sh

Option B: Windows 10 / 11

  1. Prerequisites:

    Install Python 3.10+ from python.org and check "Add python.exe to PATH".

  2. Run Windows Installer:

    Open the windows/ directory and double-click install.bat. Enter key 123456 when prompted. Automatically configures the environment and places a shortcut on your Desktop.

  3. Launch Application:

    Double-click the CDDM Live desktop shortcut, or run windows/run_cddm.bat.

Basic Operations

1. Authentication & Cookie Persistence

Enter your NASA Earthdata credentials on first start. Choose Save credentials to store tokens safely and auto-launch in future runs. OAuth tokens are persistently cached in ~/.cddis_cookies.txt to avoid repeated authorization redirects. To switch users, click 👤 User ▾ → Logout.

2. Switching Monitoring Modes

  • Live Mode: Tracks the current Julian Day in real time as hours roll over, streaming slot status dynamically.
  • DOY Audit Mode: Allows selecting any historical DOY and year to audit station archives.
  • Offline Gap Audit (📊 Gap Audit): Opens the matrix dialog to review cached summaries without generating network traffic.

3. Display-Only CSV Export

Click Export CSV at any time to generate clean tabular reports. In the Gap Audit dialog, unchecking completed days exports strictly the filtered list of missing days.

Network & Proxy Configuration

CDDM supports direct internet connections as well as university or institutional proxies.

  • Direct Internet / Home Hotspot: Operates directly over standard HTTPS port 443.
  • Institutional Proxy: Run the interactive proxy configurator: 
    ./set_proxy.sh
    Choose option 1 for Direct Internet or option 2 to enter your institute's proxy IP.

Network Troubleshooting & Auto-Repair

If you encounter login errors, SSL handshake failures, or proxy connection issues on a new machine, run the built-in diagnostic repair tool:

bash diagnose_network.sh

This tool automatically scans DNS resolution, corrects dead proxy settings, fixes ~/.netrc permission conflicts, and re-links the Mozilla SSL root certificate chain.

Uninstallation

To cleanly remove the virtual environment, cached logs, autostart entries, and local credentials at any time, run:

bash uninstall.sh
